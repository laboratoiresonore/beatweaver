# Development Tools

This directory contains development resources, research, and preparation work for Beatweaver.

## Directory Structure

```
_dev_tools/
├── preparation_work/     # Research and preparation documents
│   ├── SWITCH_ANGEL_STRUDEL_RESEARCH.md  # Comprehensive Strudel live coding research
│   ├── EXISTING_SOFTWARE_ALTERNATIVES.md # Software for controlling/simplifying Strudel
│   └── BEATWEAVER_ARCHITECTURE.md        # Complete app architecture and implementation plan
└── README.md
```

## Contents

### preparation_work/
Research documents and preparation materials:
- **SWITCH_ANGEL_STRUDEL_RESEARCH.md** - Comprehensive research on Switch Angel's Strudel live coding techniques, including 29 custom functions, production methods, and complete API reference (1000+ lines)
- **EXISTING_SOFTWARE_ALTERNATIVES.md** - Software catalog for BPM detection, tempo sync, MIDI control, and DJ integration (Pulse, Mixxx, Ableton Link, TouchOSC, etc.)
- **BEATWEAVER_ARCHITECTURE.md** - Complete software architecture for Beatweaver including: Electron + Tone.js stack, BPM detection, Novation Launch Control XL mapping, Kobold TTS integration, user-friendly preset system, and implementation roadmap
